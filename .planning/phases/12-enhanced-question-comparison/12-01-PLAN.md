<objective>
Enhance snapshot comparison to detect and display field-level changes within questions.

Purpose: Currently, question comparison only detects new/removed questions by ID. This plan adds detection of individual field changes (status, answer, body, etc.) so the user can see exactly what changed in a question between two snapshots.

Output: Updated routes.py with field-level diff logic, updated compare.html template showing all question fields with change highlighting, and localization keys for comparison field labels.
</objective>
